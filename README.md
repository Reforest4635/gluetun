# ha-gluetun-obscura

A Home Assistant add-on store repository containing a single add-on:
**Gluetun (Obscura VPN)** - runs Gluetun configured for Obscura VPN
(via its WireGuard export) and exposes an HTTP/SOCKS5 proxy for routing
*arr suite traffic through the tunnel.

See `gluetun_obscura/DOCS.md` for setup instructions.

## Add to Home Assistant

Settings → Add-ons → Add-on Store → ⋮ → Repositories → add:

```
https://github.com/Reforest4635/gluetun
```
